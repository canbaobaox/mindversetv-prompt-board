# 提示词连线板

AI 提示词连线面板 · 专业版的 MindVerseTV 原生插件。点一点，连一连，生成可直接用的提示词，还能一键发送到画布节点的提示词草稿里。

## 有什么

- **图片模式**：11 步全参数连线（角色身份、拍摄内容、**人物特征**、构图、焦距、光圈、视角、景别、光影、色调、质感）+ 画幅比例，4 个模板速选（电商服装大片、韩系清冷人像、产品静物、室内空间）。人物特征 9 组（脸型轮廓、眉骨/眉形、眼型、虹膜/瞳孔、鼻型、唇形、面部细节、气质神态、身材比例），带人物特征 SVG 图标。
- **人设视频模式**：平台与时长（Seedance 2.5 / 可灵 2.5 / Wan 2.5）、人物基准锁定段、**人物特征**（脸型轮廓、眼型+虹膜、气质神态、身材比例）、造型 6 组（妆容带色块可视化、美瞳、发型、发饰、美甲、穿搭）、场景 4 要素、时间轴剧情（可加减拍，最多 6 拍）、质感、声音，3 个模板速选（咖啡店日常、公园晨跑、居家早晨）。
- 顶部有进度连线，哪一步还没连一目了然；选择自动保存，下次打开接着连。
- **发送到画布**：在板子上连好提示词，点“发送到画布”，提示词会写进画布上图片/视频节点的“下次生成提示词草稿”，不覆盖已有成品，不启动生成，不扣费。

## 怎么装

1. 打开 MindVerseTV → 左侧导航 → **插件**，进入插件中心。
2. 点**安装插件**，选**本地插件目录**。
3. 填这个插件文件夹的完整路径，也就是仓库根目录（里面有 `package.json` 的那层），点**下一步**，核对信息后确认安装。
4. 左侧导航会出现**提示词连线板**，点开就能用；命令面板（`Ctrl+K`）搜“提示词”也能打开。
5. 打开任意画布后，画布底部工具栏会出现**提示词板**按钮，点一下在画布右侧打开提示词板浮动面板，再点一下隐藏；面板里连好提示词点“发送到画布”，会优先写进画布上选中的图片/视频节点，没选中时按画布上的同类节点处理。

改代码后不用重装：在插件中心点这个插件上的**重新加载**即可。

## 发送到画布的流程

1. 在提示词连线板上选好模式，连好选项，确认下方输出框里是想要的提示词。
2. 点输出框上方的**发送到画布**。
3. 没打开画布时会提示先打开一个画布；打开了画布，会读当前画布的图片/视频节点：
   - 画布上没有对应节点：自动新建一个图片节点（图片模式）或视频节点（人设视频模式），把提示词写进它的草稿。
   - 只有一个对应节点：直接写进它的提示词草稿。
   - 有多个对应节点：在板子上列出来，点一个写入；也可以选“新建节点”。
4. 写好后会提示“已写入某某节点的提示词草稿”，再到画布上点那个节点的生成即可。
